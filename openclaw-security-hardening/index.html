9-point hardening checklist

Every deployment we deliver
completes this checklist.

✓

Docker sandboxing configured

Containerized environment with resource limits, network restrictions, and filesystem isolation.

✓

Exec allowlist enforced

Explicit list of permitted system commands. The agent cannot execute arbitrary code outside the approved list.

✓

Firewall rules configured

Inbound and outbound rules matching the agent's actual access requirements — nothing more.

✓

Read-only permissions as default

Minimum viable permissions to start. Permissions expand gradually as trust is established.

✓

Composio OAuth middleware

All integrations run through OAuth middleware. The agent never sees your raw credentials.

✓

Audit logging enabled

Full audit trail of all agent activity — what it accessed, what actions it took, when.

✓

Update cadence established

Documented process for maintaining security through OpenClaw's monthly releases.

✓

Credential rotation completed

All setup credentials rotated after delivery. Our access window is closed before handover.

✓

Safe operating procedures documented

Runbook includes security procedures — how to revoke integrations, how to update safely.
